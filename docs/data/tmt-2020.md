# Thai Medicines Terminology 2020 data source

Medication Reader uses synthetic fixtures in its public demo. Thai Medicines Terminology (TMT) is a reference source for local evaluation of label lookup. The catalogue identifies products and their labeled strengths and forms. The original label and its evidence stay visible while a clinician reviews candidate matches. Patient dose, route, frequency, and current use come from the documented evidence and clinical review.

## Lookup fields

| Field | Use |
| --- | --- |
| TPU code | Stable source identifier for the selected catalogue record. Store it as a string with the release version. |
| Trade name and active ingredients | Search terms for brand and generic lookups. |
| Labeled strength and dosage form | Show these with each match and flag disagreements with the label. Preserve combination strengths and concentration denominators. |
| Manufacturer, dispensing unit, container quantity and unit | Help reviewers distinguish otherwise similar products when the catalogue supplies these details. |
| Generic unit code (GPU) | Group trade records linked to the same generic unit. |
| Fully specified name (FSN) | Display the publisher's full label alongside the original transcription. |

Read the product fields from `MasterTMT_20200217.xls` and join `GPUtoTPU20200217.xls` on TPU code. The archive spells these filenames `mastertmt-20200217-.xls` and `gputotpu20200217-.xls`. The separate local export keeps missing strengths blank, normalizes search text, and adds a small set of sourced aliases. Preserve the original label and keep multiple, conflicting, or missing matches unresolved for review. [Label-lookup evaluation issue](https://github.com/pakornds/Medication-Reader/issues/23)
